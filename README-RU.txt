BUILD ROULETTE — готовый проект Java 25

Форма постройки (вид сбоку):

    [любой блок]
    [любой блок]
[любой] [любой] [любой]

Всего 5 блоков: внизу три в ряд, над центральным — два.
Материал не имеет значения. Постройку можно направлять вдоль X или Z.
После установки последнего блока все 5 блоков исчезают и запускается рулетка.

СБОРКА
1. Установи JDK 25 и IntelliJ IDEA Community.
2. Открой папку как Gradle-проект.
3. В IntelliJ открой Gradle -> Tasks -> build -> build.
4. JAR будет: build/libs/BuildRoulette-1.0.0.jar
5. Перенеси JAR в папку plugins сервера и перезапусти сервер.

ВАЖНО
Проект собран с Java 25 (options.release=25). Сервер тоже должен запускаться именно на Java 25, иначе JAR не загрузится.
Для Paper 1.21.1 официально рекомендована Java 21; Java 25 официально требуется Paper 26.1+. Если сервер именно 1.21.1, безопаснее изменить в build.gradle.kts 25 на 21.

НАГРАДЫ
Все команды и шансы находятся в src/main/resources/config.yml.
%player% заменяется на ник победителя.
